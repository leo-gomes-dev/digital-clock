# 🕒 Glowing Neon Digital Clock

Um relógio digital elegante com estética Cyberpunk/Futurista. O projeto utiliza SVG dinâmico, variáveis integradas ao CSS estrutural e JavaScript nativo para criar contadores de tempo circulares que preenchem seus anéis de forma síncrona aos segundos, minutos e horas atuais.

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5 Semântico:** Estrutura limpa contendo elementos SVG inline para renderização dos vetores circulares.
* **CSS3 Avançado:**
  * **Glassmorphism:** Fundo semi-transparente com desfoque de fundo (`backdrop-filter`) gerando o efeito de vidro fosco.
  * **Tipografia Digital:** Integração das fontes premium `Orbitron` e `Poppins` via Google Fonts.
  * **Neon Glow:** Efeitos aplicados usando `drop-shadow` nos traços vetoriais e múltiplas camadas de `box-shadow` nos ponteiros de LED (`.dots`).
* **JavaScript Vanilla:** Manipulação do DOM em tempo real capturando o objeto de data nativo (`new Date()`) para atualizar as propriedades geométricas do relógio a cada segundo.

## 📦 Como Testar Localmente

1. Clone o repositório ou faça o download dos arquivos de código.
2. Certifique-se de manter os três arquivos cruciais (`index.html`, `style.css`, `main.js`) na mesma pasta raiz.
3. Abra o arquivo `index.html` em qualquer navegador web moderno para ver a aplicação funcionando instantaneamente.
